# Changelog

All notable changes to this project will be documented in this file.

## v1.0.0 — 15 July 2026

### Added

- 103 LLM engineering concepts
- 10 technical categories (Architecture, Inference, Prompt Engineering, Context Engineering, Agents, Fine-Tuning, Evaluation, Deployment, Security, Model Selection)
- Interactive Learning Roadmap (Beginner → Intermediate → Advanced)
- Expandable concept cards with details, references, and cross-links
- Instant full-text search with smart ranking (title > flags > related > description)
- Learning progress tracking (Unread / Learning / Mastered) with localStorage persistence
- Section progress counters
- Export to PDF (print), Markdown, or JSON
- Version & Source info on every card (arXiv papers, GitHub repos, official docs)
- Glossary of 25 LLM terms
- Responsive design (desktop, tablet, mobile)
- Dark mode with glassmorphism UI
- Zero external dependencies
